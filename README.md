# 🌊 부산 바다 지킴이

부산의 해양 쓰레기 문제를 함께 해결하는 시민참여형 미니앱입니다.

## 📱 프로젝트 개요

**부산 바다 지킴이**는 시민들이 해양 쓰레기를 신고하고, 그 활동에 대해 포인트를 얻으며, 지역별 랭킹을 통해 건강한 경쟁을 펼치는 플랫폼입니다.

## 🎯 주요 기능

### 1️⃣ **홈**
- 사용자의 기본 정보 및 포인트 확인
- 오늘 신고 건수 표시
- 최근 활동 내역 확인
- 전체 바다 상태 통계

### 2️⃣ **지도**
- 부산 지도에서 신고된 해양 쓰레기 위치 시각화
- 상태별 필터링 (신고됨/수거중/완료)
- 신고 목록 및 상세 정보 확인

### 3️⃣ **신고**
- 해양 쓰레기 사진 및 위치 등록
- 지역, 쓰레기 종류, 양 정보 입력
- 신고 완료 시 +50P 포인트 획득

### 4️⃣ **랭킹**
- 🏅 지역별 포인트 랭킹
- 👥 사용자별 포인트 랭킹
- 내 순위 확인
- 메달 시스템 (🥇🥈🥉)

### 5️⃣ **마이페이지**
- 👤 프로필 관리
- ⭐ 포인트 현황 및 획득 내역
- 📈 활동 통계
- 📋 내가 신고한 쓰레기 목록

## 🎨 디자인 특징

- **바다 파란색 테마**: #0066CC (주색상), #00A8E8 (보조색)
- **깔끔한 UI**: 모바일 최적화된 인터페이스
- **직관적인 네비게이션**: 하단 5개 탭 메뉴
- **반응형 디자인**: 다양한 화면 크기 대응

## 📊 포인트 시스템

| 활동 | 포인트 |
|------|--------|
| 쓰레기 신고 | +50P |
| 수거 완료 | +100P |

## 🚀 사용 방법

1. **저장소 클론**
   ```bash
   git clone https://github.com/ison09/busan-ocean-keeper.git
   cd busan-ocean-keeper
   ```

2. **파일 열기**
   - `index.html`을 웹 브라우저에서 열기
   - 또는 로컬 서버에서 실행

3. **프로필 설정**
   - 마이페이지에서 닉네임과 지역 설정

4. **쓰레기 신고 시작**
   - 신고 탭에서 사진과 위치 등록
   - 포인트 획득

## 💾 데이터 저장

- 모든 사용자 데이터는 브라우저 **로컬 스토리지**에 저장됩니다

- 다양한 기기에서 독립적으로 사용 가능
